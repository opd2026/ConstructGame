# CHANNEL ZERO

**CHANNEL ZERO** – одиночная 2D-игра о боях боевых автомобилей на арене с видом сверху. Действие происходит в будущем, где автомобильные сражения стали жестоким телевизионным шоу. Организаторы шоу сталкивают одну тяжёлую машину-Монстра с группой быстрых машин-Охотников. Игрок выбирает сторону; оставшиеся роли управляются игрой (AI).

## Требования

- Браузер на базе Chromium (Google Chrome, Microsoft Edge, Opera). Открытие папки проекта в веб-редакторе использует File System Access API, который не поддерживается в Firefox и Safari.
- Установленный [Git](https://git-scm.com/).
- Аккаунт Construct 3 (подойдёт и бесплатная версия, но у неё действуют ограничения на количество событий, слоёв и объектов).

## Клонирование репозитория

```bash
git clone https://github.com/opd2026/ConstructGame.git
cd ConstructGame
```

Для клонирования по SSH:

```bash
git clone git@github.com:opd2026/ConstructGame.git
```

## Открытие проекта в веб-редакторе

1. Перейдите на [editor.construct.net](https://editor.construct.net) и войдите в аккаунт (при необходимости).
2. В меню выберите **Open** и затем **Open project folder** (в некоторых версиях редактора пункт может называться «Open local folder»).
3. Укажите клонированную папку репозитория, в которой находится файл `project.c3proj`.
4. Разрешите браузеру доступ на чтение и запись в эту папку.

После открытия все изменения сохраняются непосредственно в папку проекта, поэтому их можно сразу просматривать и фиксировать средствами Git.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `project.c3proj` | Главный файл проекта |
| `layouts/` | Раскладки (layouts) |
| `eventSheets/` | Листы событий |
| `objectTypes/` | Типы объектов |
| `families/` | Семейства объектов |
| `scripts/` | Пользовательские скрипты (JavaScript/TypeScript) |
| `images/`, `sounds/`, `music/`, `files/` | Ресурсы проекта |
| `icons/` | Иконки приложения |

## Работа с Git

```bash
git checkout -b feature/<название>
git add .
git commit -m "Краткое описание изменений"
git push origin feature/<название>
```

Рекомендации:

- Закрывайте проект в редакторе перед выполнением `git pull` и `git checkout`, затем открывайте его заново, чтобы редактор подхватил актуальное состояние файлов.
- Не редактируйте один и тот же лист событий или раскладку одновременно в разных ветках: файлы проекта в формате JSON сложно сливать вручную.
- Для крупных бинарных ресурсов (аудио, видео, большие изображения) рекомендуется использовать [Git LFS](https://git-lfs.com/).

## Экспорт и публикация

Меню **Project → Export**: выберите нужную платформу (Web, Android, iOS, Windows, Linux, macOS и т. д.) и следуйте указаниям мастера экспорта.
